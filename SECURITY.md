# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities using GitHub's
[private vulnerability reporting](https://github.com/astro-techmath/allcrud/security/advisories/new) —
this keeps the report private while a fix is worked out.

If that's not an option, you can also email:

📧 **mathmferreira@gmail.com**

Please include as much detail as possible so the issue can be reproduced
and understood.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | ✅ Yes     |
| < 0.2   | ❌ No      |

## Security Best Practices

While Allcrud follows good design principles and validation by default, it
is the responsibility of the implementer to:

- Validate user input appropriately
- Handle authentication and authorization
- Configure services according to your environment's security standards

Thank you for helping keep Allcrud safe and reliable.
